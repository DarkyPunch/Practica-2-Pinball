# Práctica 2 - Pinball

Alejandro Mata Vizcaíno

## Controles

* **Flipper Izquierdo:** `Q`
* **Flipper Derecho:** `E`
* **Lanzador:** `Espacio`
* **Reset:** `R`

## Valores Físicas Bola

* **Friction:** `0.5`
* **Static Friction:** `0.0`
* **Restitution:** `0.75`
* **Density:** `1.0 g/cm3`
* **Simulate Physics:** ON
* **CCD:** ON

## Mejoras Implementadas

Cada vez que la bola golpea uno de los bouncers asignados por el tag del mismo nombre, dicho bouncer se ilumina del color que le corresponde y se apaga a los pocos segundos, indicando al jugador que ha sumado puntuación en el marcador.
